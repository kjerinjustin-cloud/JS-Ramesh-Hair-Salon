# J S Ramesh Hair Salon — Website

Single-page website for **J S Ramesh Hair Salon (Ramesh Hair Stylist)**, Koramangala 2nd Block, Bangalore.

## Files

```
index.html      — main page
css/style.css   — styles
js/main.js      — animations & form logic
images/         — salon photos (10 .jpg)
```

## How to publish on GitHub Pages

1. Create a new repository (e.g. `ramesh-hair-stylist`).
2. Upload **all files and folders** from this zip to the repository root (keep the `css`, `js`, `images` folders as they are).
3. Open **Settings → Pages**.
4. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: `main`, folder: `/ (root)`
5. Click **Save**. After ~1 minute your site is live at:
   `https://<your-username>.github.io/ramesh-hair-stylist/`

> Note: do **not** upload the zip itself into the repo — extract it first.

## Edit later

- Phone / WhatsApp number: search `999999999999` in `index.html` and replace with the real number (country code without `+`, e.g. `919876543210`).
- Prices: edit the text in `index.html` under the Services section.
- Opening hours: Mon & Wed–Sun 7:30 AM – 9:30 PM, Tuesday closed.
